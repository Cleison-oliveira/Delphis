# Delphis 🐬✨
### Dolphin Texture Manipulation Tool (.NET 8)

[![NixOS Flake](https://img.shields.io/badge/NixOS-Flake%20Ready-5277C3?logo=nixos&logoColor=white)](https://nixos.org)
[![.NET 8.0](https://img.shields.io/badge/.NET-8.0%20C%23%2012-512BD4?logo=dotnet&logoColor=white)](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
[![Tests](https://img.shields.io/badge/Tests-xUnit%20Passing-brightgreen?logo=xunit&logoColor=white)](tests/Delphis.Tests/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**Delphis** is a modern, high-performance C# (.NET 8) texture manipulation suite and standalone Nix Flake designed for high-resolution texture pack workflows in the **Dolphin Emulator** (GameCube & Wii). It bridges Dolphin's tonemap and texture hash architecture with 4-channel neural AI upscaling, anti-aliased alpha transparency editing, and DirectDraw Surface (DDS) hardware block compression.

---

## 🚀 Running Directly from Repository

### 1. Direct Execution via Nix Flake (`nix run`)

```bash
# 🐬 Run Delphis directly from repository
nix run github:Cleison-oliveira/Delphis -- --help

# 🔍 Run System & GPU Doctor
nix run github:Cleison-oliveira/Delphis -- doctor

# 📦 Run the DolphinTextureExtraction CLI (dte)
nix run github:Cleison-oliveira/Delphis#dte -- HELP

# 🧪 Run the full automated test suite directly from repo
nix run github:Cleison-oliveira/Delphis#test
```

### 2. Standard .NET 8 CLI

```bash
git clone https://github.com/Cleison-oliveira/Delphis.git
cd Delphis

# Run tests
dotnet test Delphis.sln

# Run Delphis CLI
dotnet run --project src/Delphis.Cli/Delphis.Cli.csproj -- doctor
dotnet run --project src/Delphis.Cli/Delphis.Cli.csproj -- alpha "/path/to/in.png" "/path/to/out.png" --alpha 130 --smooth
dotnet run --project src/Delphis.Cli/Delphis.Cli.csproj -- dds "/path/to/in_dir" "/path/to/out_dir" --preset BC7
dotnet run --project src/Delphis.Cli/Delphis.Cli.csproj -- upscale "/path/to/in.png" "/path/to/out.png" --scale 4 --model realesrgan-x4plus-anime
dotnet run --project src/Delphis.Cli/Delphis.Cli.csproj -- dte merge_rgba "/path/to/dump" "/path/to/merged" --tasks 4 --no-logs
```

### 3. DTE Log File Control (`--logfile` / `--no-logfile`)
The DTE extraction and tonemap merge module supports granular control over `.log` file generation on disk:
- **Real-time Console Output**: DTE stdout output (`[01] Info: ...`) is always streamed in real time to the GUI Console Drawer and terminal.
- **GUI Configurable**: In the **Extraction (DTE)** tab, toggle **"Generate DTE Log File (.log in output folder)"**. When unchecked, Delphis automatically cleans up `DTE-*.log` files from the output folder.
- **CLI Flags**: Pass `--no-logfile` (or `--no-log`) to delete log files, or `--logfile` to retain them on disk.

## 🌟 Key Features & Modules

### 1. 🟦 Extraction & Tonemaps (`Delphis.Core.Services.DteOrchestrator`)
- **Game Texture Dumper**: Dumps raw textures directly from GameCube & Wii ISOs, WBFS, and RVZ dumps matching Dolphin's internal texture hash format.
- **Grayscale Tonemap Combiner**: Reconstructs split grayscale pairs (`RGBA_*` and `BGRA_*`) generated by Dolphin into single, editable high-resolution RGBA PNG textures (`CombineRGBA` / `CombineBGRA`).
- **Finalize & Split**: Takes upscaled or manually retouched textures, splits them back into Dolphin's expected grayscale tonemap channels, and optimizes them for in-game injection (`Finalize`).

### 2. 🟨 Alpha & Transparency Processor (`Delphis.Core.Services.AlphaProcessor`)
- **Proportional Sub-Pixel Opacity (`0` to `255`)**: Fine-grained alpha adjustment with quick preset levels (`255` Opaque, `192` 75%, `130` Dolphin UI/Glass, `64` 25%, `0` Transparent).
- **Sub-Pixel Anti-Aliasing**: Proportional alpha scaling prevents jagged binary cutouts and preserves smooth edges.
- **Defringing Algorithm**: Unmultiplies color channels using alpha weighting ($C_{unmult} = \min(255, \frac{C \times 255}{\alpha})$) to eliminate discolored halos around semi-transparent edges.
- **Gaussian Edge Smoothing**: Softens pixelated mask borders.

### 3. 🟩 AI Upscaler with 2-Layer RGB+A Separation (`Delphis.Core.Services.UpscalerEngine`)
- **Optimized 2-Layer Pipeline**: Decouples image data into only **RGB Color** (PNG24) and **Alpha Transparency** (Grayscale) layers, eliminating inefficient 4-channel splits.
- **Direct 1-Pass Mode for Opaque Textures**: Automatically detects images without transparency and executes a direct 1-pass RGB upscale without unnecessary alpha extraction.
- **Pixel-Perfect Seam & Geometry Alignment (2x, 3x, 4x)**: Probes exact input dimensions and strictly enforces target geometry (`(Width * scale) x (Height * scale)!`) on both color and alpha layers, eliminating 1-pixel seam discrepancies, cuts, and misalignment when adjacent tiles are joined in Dolphin.
- **Models**: `realesrgan-x4plus-anime`, `realesrgan-x4plus`, `realesrnet-x4plus`.
- **Scaling Factors**: `2x`, `3x`, `4x`.
- **Vulkan GPU Acceleration**: Auto-detects discrete NVIDIA/AMD GPUs via Vulkan device enumeration.

### 4. 🟪 DDS Texture Optimizer (`Delphis.Core.Services.DdsOptimizer`)
- **DirectDraw Surface Acceleration**: Converts PNG textures to `.dds` hardware block compression formats natively decoded by GPU texture units.
- **Presets Tailored for Dolphin**:
  - **BC7**: High-Quality RGBA (Recommended standard for modern HD texture packs).
  - **BC1 / DXT1**: High-Performance Opaque textures (no alpha).
  - **BC1a**: 1-Bit Cutout transparency.
  - **BC3 / DXT5**: Interpolated Alpha for broad legacy compatibility.
  - **BC5**: Two-channel format designed for tangent-space Normal / Bump maps.

## ⚙️ Declarative NixOS & Home Manager Configuration

### NixOS System Module
```nix
{
  inputs = {
    nixpkgs.url = "github:nixos/nixpkgs/nixos-unstable";
    delphis.url = "github:Cleison-oliveira/Delphis";
  };

  outputs = { self, nixpkgs, delphis, ... }: {
    nixosConfigurations.myhostname = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        delphis.nixosModules.default
        {
          programs.delphis.enable = true;
        }
      ];
    };
  };
}
```
